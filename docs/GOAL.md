# Omni Geo Quiz 目标

最后更新：2026-10-23。由 Jiaming 和 Claude 一起定下。

这份文件约束后面所有的工作。每个改动都要推进下面的某一条完成标准，推进不了的就不做。
新的 session 开始时，先读这份文件和 `CLAUDE.md`，再看最下面的进度表。

## 北极星

让 Omni Geo Quiz 成为航空迷和地理迷**每天愿意回来玩一局、并且愿意分享成绩**的免费网页游戏。

## 完成标准

1. **每日挑战**：每天一套混合题（US/World、城市/机场混在一起），全世界同一天是同一套题。
   一键复制 emoji 成绩加链接，在本地记录连胜。不需要后端，题目由日期决定。
2. **每个页面都有自己的网址**：`/daily`、每个模式、结果页都能直接分享，浏览器返回键正常。
3. **首页能容纳 10 个以上的模式**：保留现在的风格（复古按钮、硬阴影、`#FF4F00`、星球），
   重新组织成"第一屏是星球、标题和今日挑战，往下滚是按分组排列的模式卡片，最下面是 About 和署名"。
4. **合规**：每一类图片都写清楚来源和许可，界面上显示 Google 署名，有一个 About 页。
5. **质量不倒退**：`npm run lint` 0 错误，`npm run build` 通过。模糊匹配交叉扫描和坐标扫描
   改成脚本并放进 CI，这样放手改的时候有安全网。
6. **新内容**，每一个都和现有模式一样，在结果页带 Wikipedia 链接：
   - **按大洲玩**：World City / World Airport 可以按大洲选（北美、南美、欧洲、亚洲、非洲、大洋洲）。
   - **尾翼认航空公司**（Tail Fin Quiz）：只看垂直尾翼上的图案，猜是哪家航空公司。
   - **机型识别**（Aircraft Type Quiz）：看飞机照片，猜机型。
   - **扩充世界城市**：每个大洲都有足够的城市，按大洲玩才有意义。
7. **可以直接拿去推广**：分享链接时有预览图（Open Graph meta），有一段简短的玩法说明，
   还有一份能直接发到 Reddit 的帖子草稿。

## 明确不做

- 赚钱、广告。
- 账号、后端、服务器。
- GeoGuessr 那样的距离打分。不和 GeoGuessr 做一样的东西。
- 跑道布局认机场、世界国家地图、限时模式。评估过了，Jiaming 觉得一般。
- 原生 App、多人对战。

## 硬约束

- 遵守 `CLAUDE.md` 里的 Design System 和 Responsive Layout 规则。
- 新图片只用有明确许可的来源（比如 Wikimedia Commons 上的 CC 或公有领域图片），
  每张图都记下来源、作者和许可证，并在界面上署名。
- 题目图片不能把答案露出来：尾翼图要裁掉机身上的航空公司名字，
  机型图要裁掉机身上写着的型号（比如 "787 Dreamliner"、"A350 XWB"）。
