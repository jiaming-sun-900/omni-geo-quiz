# 发布帖子草稿

发帖前先读一下每个版块的规则。很多版块对"推广自己的作品"有限制，比如只能在固定的帖子里发、
必须选 Self-promotion 标签，或者要求账号先有一定的活跃度。下面的草稿只是起点，我没法替你确认
各版块当前的规则（这个环境访问不了 Reddit）。

建议的顺序：先发一个规则最宽松的版块（比如 r/WebGames），看看反馈，修修 bug，再去发大一点的版块。
每天的帖子最好间隔开，并且在评论区回复每一条留言。
